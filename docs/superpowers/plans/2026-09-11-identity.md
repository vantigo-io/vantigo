# Identity (Go port sub-project 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Go server serves all 101 operations of `openapi/identity.yaml` with the .NET identity module's behaviour, single-tenant, on a platform later modules mount on.

**Architecture:**
- **Platform packages** (`contracts`, `module`, `secrets`, `mail`, transactions, sqlc) come first.
- **Access enforcement** is a `module.Router`. It implements the generated `ServeMux` interface and wraps every operation with the rate limit and the contract's `x-vantigo-access` rule before the generated wrapper runs.
- **Identity** is one package, `internal/identity`, with one file per area. Its `*server` implements the generated `StrictServerInterface`, and its `*Access` implements `contracts.Access`.
- **Data** lives in the `identity` PostgreSQL schema, accessed through sqlc.

**Tech Stack:**
- Go 1.27, stdlib `net/http`
- pgx v5 and goose; sqlc v1.31.1 (mise, aqua)
- kin-openapi v0.149.0
- oapi-codegen v2.8.0 (already generated code)
- `golang.org/x/crypto` v0.57.0 (argon2, hkdf)
- `github.com/pquerna/otp` v1.5.0
- `github.com/go-webauthn/webauthn` v0.18.1
- `github.com/coreos/go-oidc/v3` v3.21.0 and `golang.org/x/oauth2` v0.37.0
- `github.com/wneessen/go-mail` v0.8.1
- `github.com/google/uuid`

**Spec:** `docs/superpowers/specs/2026-09-11-identity-design.md`. Parent: `docs/superpowers/specs/2026-09-10-go-backend-port-design.md`. The behavioural reference is `docs/superpowers/specs/2026-09-11-identity-inventory.md` (the .NET module's behaviour, with file references) plus the .NET code and tests under `apps/identity/backend/`.

## Global Constraints

- **Contract.** Serve exactly `openapi/identity.yaml` and never edit `openapi/*.yaml`. If the contract looks wrong, stop and report it.
- **No framework.** Stdlib `net/http`. Identity has no ServeMux conflicts, so the inner mux is `http.ServeMux`.
- **Pinned libraries.** Use exactly the versions in Tech Stack; add them with `go get <module>@<version>`. sqlc runs from `mise.toml` (`"aqua:sqlc-dev/sqlc" = "1.31.1"`) via a `go:generate` directive.
- **Import boundaries.** `internal/identity/...` imports only `internal/contracts`, `internal/module`, platform packages (`config`, `db`, `httpx`, `mail`, `secrets`, `ratelimit`, `openapi`, `apicommon/gen`) and its own subpackages. Never another module. `depguard` enforces this from Task 6.
- **Schema.** All identity tables live in schema `identity`. No query or migration references another schema (one exception: the rate limiter's `platform` schema is reached only through `internal/ratelimit`).
- **Identity error bodies:**
  - `AuthErrorResponse` `{"error":{"code","message","fields"}}` for handler errors
  - flat `CodeMessageError` `{"code","message"}` under `/access/*`, and the maintenance 400
  - SCIM error bodies for `scim` operations
  - OIDC failures are 302 `/sign-in?error=<code>`
  - the access layer answers 401 `unauthenticated` (message "Authentication is required.") and 403 `forbidden` (message "You do not have permission to access this resource.")
  - decode errors get 400 `invalid_request` ("The request is invalid.")
  - never echo `err.Error()` to a client
- **Time.** Identity code never calls `time.Now()`. It uses `deps.Clock()`, and time-dependent SQL takes `now` as a parameter.
- **Tests:**
  - Identity tests run against real PostgreSQL via `internal/testdb`.
  - Every ported test carries a comment naming the .NET test: `// Ported from IdentityPasswordAuthIntegrationTests.Login_logout_lifecycle.` The .NET test is the specification of a ported test; this plan names each test and its essential assertions, and the implementer reads the .NET test for the rest.
  - All identity HTTP traffic goes through the harness client, which validates every exchange against `identity.yaml`. Deliberate off-contract probes (CSRF, malformed input) opt out explicitly, with a comment.
  - Test files are `*_test.go` in package `identity_test`, except pure unit tests of unexported helpers.
- **Secrets.** Never log them. Compare secrets and tokens in constant time (`crypto/subtle`). Store only SHA-256 of tokens and recovery codes, and Argon2id PHC of passwords. TOTP secrets are encrypted with `secrets.Box`.
- **Generated code.** oapi-codegen and sqlc output is regenerated with `cd apps/server && mise exec -- go generate ./...` and never hand-edited.
- **Tools.** Run Go tools through mise from `apps/server`: `mise exec -- go …` and `mise exec -- golangci-lint run`.
- **Commits** end with:

### Task 1: Identity configuration

**Files:**
- Modify: `apps/server/internal/config/config.go`
- Test: `apps/server/internal/config/config_test.go`

**Interfaces:**
- Produces `Config` fields:
  - `AppSecret []byte`
  - `BootstrapSecret string`
  - `SystemAdminEmail string`
  - `Sessions SessionConfig{Idle, PrivilegedIdle, Absolute, PrivilegedAbsolute time.Duration}`
  - `OwnersRequireMFA bool`, `OwnersAllowInsecureNoMFA bool`, `MFAIssuer string`
  - `InvitationLifetime time.Duration`, `InvitationAcceptURL string`, `PasswordResetURL string`
  - `Mail MailConfig{Driver string /* "smtp"|"log" */, Host string, Port int, Username, Password, From string, TLS string /* "implicit"|"starttls"|"none" */}`
  - `OIDC *OIDCConfig` (nil when disabled): `{Provider string /* "entra"|"google" */, Authority, ClientID, ClientSecret, WorkloadTokenFile string, AllowedDomains []string, DisplayName string}`
  - `SCIM *SCIMConfig` (nil when disabled): `{Token, PreviousToken string, PreviousTokenExpiresAt time.Time}`
  - `TrustedProxyCIDRs []netip.Prefix`

- [ ] **Step 1: Write the failing tests.** Add table cases to `config_test.go` in the file's existing style (`Load(env)` with a map). Cover:
  - `APP_SECRET` missing or shorter than 32 bytes → problem naming `APP_SECRET`; the value is never quoted
  - `BOOTSTRAP_SECRET` required when `APP_ENV=production`, optional in development
  - `SESSION_*` defaults 8h/2h/24h/8h; a zero or negative value → problem; a privileged value larger than the standard one → problem
  - `OWNERS_REQUIRE_MFA` defaults to `1` in production and `0` in development; production with `OWNERS_REQUIRE_MFA=0` and no `OWNERS_ALLOW_INSECURE_NO_MFA=1` → problem
  - `MFA_ISSUER` default `Vantigo`
  - `INVITATION_LIFETIME` default `168h`; outside 24h–720h → problem
  - `INVITATION_ACCEPT_URL` without `{token}` → problem
  - `PASSWORD_RESET_URL` without `{token}` or `{email}` → problem
  - `MAIL_DRIVER` defaults to `smtp` in production and `log` in development; `log` in production → problem
  - smtp needs `SMTP_HOST` and `SMTP_FROM` (an address); `SMTP_PORT` default 587
  - `SMTP_TLS` default `starttls`; `none` needs `ALLOW_INSECURE_TRANSPORT=1` or development
  - OIDC is all-or-nothing on `OIDC_PROVIDER`:
    - entra requires `OIDC_AUTHORITY` of exactly `https://login.microsoftonline.com/<guid>/v2.0`, a GUID `OIDC_CLIENT_ID`, and no `OIDC_ALLOWED_DOMAINS`
    - google requires `OIDC_AUTHORITY=https://accounts.google.com`, a client id ending `.apps.googleusercontent.com`, and at least one domain
    - exactly one of `OIDC_CLIENT_SECRET` or `OIDC_WORKLOAD_IDENTITY_TOKEN_FILE` (falling back to `AZURE_FEDERATED_TOKEN_FILE`); workload identity is entra-only and needs an absolute path
    - `OIDC_DISPLAY_NAME` default `Workforce SSO`

    Mirror `packages/configuration/Vantigo.Configuration/WorkforceOidcOptions.cs:42-149`.
  - SCIM is enabled by `SCIM_TOKEN`:
    - the token must be non-empty with no whitespace
    - `SCIM_PREVIOUS_TOKEN` needs `SCIM_PREVIOUS_TOKEN_EXPIRES_AT` (RFC 3339), in the future and at most 24h ahead, and different from the current token
  - `TRUSTED_PROXY_CIDRS` is a comma list of prefixes; an invalid entry → problem; empty → none

package contracts

// Permission is one catalog entry, "module:verb".
type Permission struct {
	Key         string
	Display     string
	Description string
	Sensitive   bool
	Delegable   bool
}

// ValidatePermission checks the key grammar ([a-z]+:[a-z0-9_-]+), a

type RuleKind uint8

const (
	RuleAnonymous RuleKind = iota
	RuleSession
	RuleSCIM
	RulePolicy
	RulePermission
)

// Rule is a parsed x-vantigo-access value. Names are the policies or
// permission keys, in the contract's (sorted) order.
type Rule struct {
	Kind  RuleKind
	Names []string
}

func ParseRule(s string) (Rule, error)
func (r Rule) String() string

// Principal is the authenticated caller of one request.
type Principal struct {
	UserID      uuid.UUID
	SessionID   uuid.UUID
	Roles       []string
	MFAVerified bool
	SCIM        bool // authenticated by the SCIM bearer token; no user
}

func WithPrincipal(ctx context.Context, p Principal) context.Context
func PrincipalFrom(ctx context.Context) (Principal, bool)

var (
	ErrUnauthenticated = errors.New("unauthenticated")
	ErrForbidden       = errors.New("forbidden")
)

// Access authenticates a request and evaluates an access rule. Identity
// implements it; every module's router uses it.
type Access interface {
	// Check returns the caller if rule is satisfied. For RuleAnonymous it
	// never fails on credentials: it returns the caller when a valid session
	// exists, else a zero Principal. It returns ErrUnauthenticated or
	// ErrForbidden (possibly wrapped) when the rule is not met, and any other
	// error for infrastructure failures.
	Check(r *http.Request, rule Rule) (Principal, error)
	// Reject writes the response for ErrUnauthenticated/ErrForbidden under rule.
	Reject(w http.ResponseWriter, r *http.Request, rule Rule, err error)
}
